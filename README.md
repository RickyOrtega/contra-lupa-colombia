# ContraLupa

ContraLupa es un proyecto personal pensado para optimizar y simplificar las búsquedas en el SECOP y DatosAbiertos. Entre las funcionalidades previstas tenemos/tendremos:

- Acceso y consulta de los procesos de contratación.
- Parametrización y normalización de los datos.
- Analítica avanzada de los datos.
